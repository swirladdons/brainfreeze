# Brain Freeze
Shows the bonus rolls the [SimulationCraft addon](https://github.com/simulationcraft/simc-addon) has recorded for your character: what you won, which spec it counted for, the roll pool, where it dropped (with the key level for Mythic+) and date.

Reads SimC's saved data directly, so it updates after every roll. You can also paste a `/simc` export (or just the `bonus_roll_items` line) with Import.

`/brainfreeze` or `/bfreeze` toggles the window, `/bfreeze import` opens the paste box, `/bfreeze clear` forgets the pasted export.
