# Brain Freeze
Bonus roll history for every character: what you won, on which spec, from which boss, and at what difficulty.

Reads the rolls the [SimulationCraft addon](https://github.com/simulationcraft/simc-addon) records directly, so it updates after every roll. You can also paste a `/simc` export (or just the `bonus_roll_items` line) with Import.

`/brainfreeze` or `/bfreeze` toggles the window, `/bfreeze import` opens the paste box, `/bfreeze clear` forgets the pasted export.
